# Method index

All 134 method skills, grouped by project stage. Grade: A = tested in peer-reviewed research, B = established professional standard, C = practitioner tool with little formal testing, Local = the agency's own evidence. The grade is about the method's evidence, not about how well this repository's skill was written. Each skill file ends with a Sources section listing what was actually opened.
